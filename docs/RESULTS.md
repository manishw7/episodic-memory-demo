**Artifacts:** [`../eval_results/eval_report.md`](../eval_results/eval_report.md),

These numbers are not re-generated by reading this document. They are the output of the run stored in

because every case calls the real local models.

## How scoring works

Scoring is **deterministic and rule-based**. The model is never asked "did you do well?". Each case
carries gold labels, and the runner checks:

- whether stored episode text contains the required keywords (formation),
- whether forbidden phrases appear in episode titles (noise),
- cosine rank position of the gold episode (retrieval),
- status and type in SQLite (lifecycle),
- required/forbidden substrings in the answer, and abstention phrases (answering),
- whether the answer changes when memory is off, changed, or deleted (causal),
- whether the system survives restart, deletion, injection, flood, and an empty archive (stress).

That makes the scores reproducible in the sense that the *checks* are fixed. The model outputs still
vary between runs.

## What these numbers prove

- The extraction pipeline is selective on this gold set: 17/17, no duplicates, no invented memories.
- The lifecycle rules produce the expected status changes in all six designed scenarios.
- The answer prompt uses evidence, applies a stored format preference, and abstains when the archive
  has nothing.
- The system survives restart, deletion, prompt injection, a 40-item distractor flood, and an empty
  archive.

## What they do not prove

1. **Retrieval is measured without the production floor.** `run_retrieval` calls
   `retrieve(..., min_similarity=-1.0)` (`evaluate.py:288`), so top-1 69% describes ranking, not what a
   user sees with `MEMORY_MIN_SIMILARITY=0.30`.
2. **Four of six sections bypass extraction.** Retrieval, answering, causal, and stress insert
   episodes with `seed_episode` (`evaluate.py:161`), which calls the private `_insert_episode` directly.
   Validation, grounding, dedupe, and lifecycle are skipped there.
3. **The sample is small.** 13 retrieval cases is an engineering measurement, not statistical proof.
4. **The data is synthetic.** Cases are hand-written, not collected from real users.
5. **The 30-episode routing cap is never exercised**, because every test archive is small.
6. **Contradiction resolution is untested beyond `c4`**, and `c4` fails.

## Reproduce

```bash
source .venv/bin/activate
python evaluate.py                    # all sections, temporary database
python evaluate.py --sections formation,retrieval
```
